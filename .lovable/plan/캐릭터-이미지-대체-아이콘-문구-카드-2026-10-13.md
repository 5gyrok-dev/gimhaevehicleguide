# 캐릭터 이미지 대체: 아이콘 + 문구 카드

## 목표
삭제한 토더기 캐릭터 이미지 자리를 이미지 없이 채운다 — 파란색 톤 아이콘과 짧은 안내 문구로 구성한 카드/배지. 기존 기능·구조·화면 흐름은 전혀 바꾸지 않는다.

## 원칙
- 새 이미지 에셋 없음, 로딩 없음
- 파란색 톤만 사용 (노랑·크림 금지), 기존 토큰(bg-primary/10, text-primary, text-muted-foreground)만 사용
- 모든 새 문구는 5개 언어(한국어·영어·중국어·베트남어·우즈베크어) 번역을 guide-content.ts에 추가
- 버튼·진행 표시·문서 예시 등 기존 요소는 손대지 않음

## 화면별 구성

### 1. 시작 화면 (기존 대형 이미지 자리, 가운데)
- 원형 배지(배경 bg-primary/10) 안에 큰 `Car` 아이콘 (text-primary)
- 아래에 한 줄 문구 (새 키 `startTip`), 예: "화면을 따라 차근차근 준비하세요"
- 전체 높이가 기존 이미지 자리(my-6, 최대 320px 영역)와 비슷하게 유지

### 2. 하단 여백 자리 (언어/업무/방문 유형/준비/보험/보험 안내/체크/주소/주소 안내, 9곳)
- 기존 빈 여백 div를 유지하되 그 안에 작은 배지 추가: 작은 `Car` 아이콘 + 한 줄 공용 문구 (새 키 `footTip`), 예: "순서대로 따라오시면 돼요"
- text-sm, text-muted-foreground — 눈에 띄지 않고 반복되어도 거슬리지 않게
- 모든 화면에서 동일한 배지 하나만 사용 (문구 반복 최소화)

### 3. 신청서 작성 화면 헤더 (오른쪽 작은 이미지 자리)
- `FileText` 아이콘 배지(h-16 w-20 크기 유지, bg-primary/10 원형) — 문구 없이 아이콘만

### 4. 마지막 화면 (기존 대형 이미지 자리)
- `CircleCheck` 큰 아이콘 (text-primary) + 한 줄 문구 (새 키 `finishTip`), 예: "준비가 끝났어요"
- 시작 화면과 같은 배지 스타일로 통일

## 수정 파일
1. `src/guide-content.ts` — 새 키 3개(`startTip`, `footTip`, `finishTip`)를 5개 언어로 추가
2. `src/routes/index.tsx` — 빈 자리 div에 위 배지/카드 배치, lucide 아이콘 import 추가(CircleCheck 등)

## 검증
- 빌드 로드 OK 확인
- Playwright(390px, 아이폰12 Pro 기준)로 시작 → 업무 → 방문 유형 → 준비 → 신청서 작성 → 마지막 화면 스크린샷 확인
- 한국어 외 영어 1개 언어로 새 문구 표시 확인
- 진행 표시·버튼·기존 문구에 변화 없음 확인
